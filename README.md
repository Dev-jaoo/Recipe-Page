# 🍳 Recipe Page

Este projeto consiste na construção de uma página de receita, desenvolvida como parte de um desafio da plataforma [Frontend Mentor](https://www.frontendmentor.io/).

O objetivo foi reproduzir o layout proposto, praticando conceitos de HTML semântico, estilização com CSS e responsividade.

## 📸 Preview

![Preview do projeto](./assets/images/preview.jpg)

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, pratiquei:

- Estruturação de páginas utilizando HTML semântico.
- Organização de conteúdo com elementos como `main`, `section`, `ol`, `ul` e `table`.
- Criação e utilização de variáveis CSS com `:root`.
- Aplicação de fontes personalizadas com Google Fonts.
- Utilização de Flexbox para organização de elementos.
- Estilização de listas com pseudo-elementos, como `::marker`.
- Utilização de pseudo-classes, como `:last-child` e `:nth-last-child()`.
- Criação de layouts responsivos utilizando Media Queries.
